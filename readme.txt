=======================================================================
🌍 MCMultiplayer (v5.3.2) — ИНСТРУКЦИЯ ДЛЯ ИГРОКОВ
=======================================================================

Этот мод позволяет в один клик сделать твой одиночный мир глобальным 
сервером, чтобы к тебе могли зайти друзья через интернет! 
Больше не нужен платный хостинг, Realms или лагающий Aternos.

Версия игры: Minecraft 1.20.1 (Forge)
Поддержка лаунчеров: Лицензия и Пиратки (TLauncher, Legacy и др.)

-----------------------------------------------------------------------
🎮 ИНСТРУКЦИЯ ДЛЯ ТОГО, КТО ЗАПУСКАЕТ МИР (ХОСТ)
-----------------------------------------------------------------------

1. Установи этот мод в папку .minecraft/mods/ своего компьютера.
2. Запусти Майнкрафт 1.20.1 Forge и зайди в свой одиночный мир.
3. Нажми клавишу ESC, чтобы открыть меню паузы.
4. Внизу экрана выбери режим протокола:
   - Protocol: UDP (Рекомендуется) — для быстрой настройки.
   - Protocol: TCP — если роутер старый или блокирует UDP.
5. Введи желаемый порт (можно оставить по умолчанию вашпорт).
6. Нажми кнопку "Open WAN", чтобы запустить мир в сеть.
7. Снова нажми ESC и нажми появившуюся кнопку "Make Global IP Server".
8. Посмотри в левый верхний угол экрана. Как только там загорится 
   ЗЕЛЕНЫЙ статус "UPnP Success! Port Open", твой сервер запущен!
9. Нажми английскую клавишу "V" на клавиатуре — твой рабочий 
   Глобальный IP и порт автоматически скопируются в буфер обмена.

-----------------------------------------------------------------------
👥 КАК ПОДКЛЮЧИТЬСЯ ДРУЗЬЯМ (ИГРОКАМ)
-----------------------------------------------------------------------

1. У игроков должен быть установлен ТОЧНО ТАКОЙ ЖЕ набор модов 
   и та же версия игры (1.20.1 Forge). Этот сетевой мод им тоже нужен!
2. Хост скидывает вам скопированный адрес (например: вашipилидругойip).
3. Зайдите в Майнкрафт -> Сетевая игра -> По адресу (Direct Connection).
4. Вставьте адрес, который вам скинул хост, и нажмите "Подключиться".

🛠️ ПОДРОБНЫЙ РАЗБОР ПРИЧИН ОШИБКИ "Connection timed out"
-----------------------------------------------------------------------

Если у хоста горит зеленый статус успеха, но друг не может зайти, 
это происходит по двум конкретным сетевым причинам:

ПРИЧИНА №1: Блокировка Брандмауэром Windows (Не рекомендуем, если вы не хотите это делать то это правильно лучше надо №1.1)
- Что происходит: Роутер успешно пропускает друга в твою сеть, но 
  встроенный защитник Windows (Firewall) на твоем компьютере видит 
  незнакомое TCP-подключение из интернета к процессу Java и намертво 
  его сбрасывает. Локальных игроков (LAN) он пускает, а внешних — нет.
- Как исправить хосту: Полностью ОТКЛЮЧИТЬ Брандмауэр Windows. 
  (Нажми Win+R -> введи control firewall.cpl -> слева выбери "Включение 
  и отключение брандмауэра Защитника Windows" -> переставь обе галочки 
  в положение "Отключить" -> нажмите ОК).

### ПРИЧИНА №1.1: Блокировка Брандмауэром Windows (Рекомендуем)
- Что происходит: Роутер успешно пропускает друга в твою сеть, но 
  встроенный защитник Windows (Firewall) на твоем компьютере видит 
  незнакомое TCP-подключение из интернета к процессу Java и намертво 
  его сбрасывает. Локальных игроков (LAN) он пускает, а внешних — нет.
- **Как исправить хосту (Безопасный способ):** Добавить Java в исключения, чтобы не отключать защиту компьютера целиком.
  1. Нажми **Win + R** -> введи `control firewall.cpl` -> нажми ОК.
  2. Слева выбери **"Разрешение взаимодействия с приложением или компонентом..."**.
  3. Нажми кнопку **"Изменить параметры"** вверху справа.
  4. Найди в списке все строки **Java(TM) Platform SE binary** или **OpenJDK Platform binary**.
  5. Поставь напротив них галочки как в столбце **"Частная"**, так и в **"Публичная"**.
  6. Нажми ОК для сохранения.

ПРИЧИНА №2: "Серый IP-адрес" у провайдера
- Что происходит: Твой провайдер (например, Дом.ру) выдает твоему 
  роутеру адрес из своей внутренней подсети (за двойным NAT). Твой мод 
  успешно открывает порт на твоем домашнем роутере, но на главном 
  оборудовании провайдера эта дверь остается закрытой. В итоге твой 
  глобальный IP из интернета просто не может достучаться до твоего дома.
- Как проверить хосту: Зайди на сайт 2ip.ru и посмотри свой IP. Затем 
  открой панель роутера (вашip) во вкладке "WAN" или "Статус" 
  и сравни адрес там. Если они РАЗНЫЕ — твой IP серый.
- Как исправить: Включить услугу "Белый / Статический IP" в личном 
  кабинете провайдера (обычно стоит около 100 рублей в месяц) или 
  использовать альтернативный режим туннелирования.

-----------------------------------------------------------------------
👑 УПРАВЛЕНИЕ СЕРВЕРОМ И ЗАЩИТА ОТ ГРИФЕРОВ (КОМАНДЫ)
-----------------------------------------------------------------------

Поскольку сервер становится глобальным, к тебе могут зайти незваные 
гости. Мод добавляет мощные встроенные команды администрирования:

* /ban <ник> [причина] — Мгновенно блокирует вредителя по его нику.
* /ban-ip <ip_или_ник> — Намертво банит игрока по его сетевому IP. 
  Даже если грифер сменит ник в лаунчере, он больше не сможет зайти. 
  Мод сам автоматически очищает IP от лишних символов и слэшей.
* /pardon <ник> / /pardon-ip <ip> — Быстрое помилование и удаление 
  игрока из черного списка без перезапуска игрового мира.

Если вы хотите пойти поиграть на Hypixel или других сторонних серверах, 
и не хотите, чтобы мод автоматически лез в сеть и дорисовывал сервера:

1. Зайдите в главное меню игры -> Моды (Mods) -> выберите MCMultiplayer 
   и нажмите кнопку "Настройки" (Config).
2. Вы увидите новую кнопку: "MCMultiplayer Mod".
3. Переключите её в положение "OFF" — настройки сохранятся на диск.
4. После этого мод полностью "заснёт": он очистит все сокеты Java, 
   освободит интернет-каналы и уберёт авто-добавление IP из списков.
5. Чужие сервера будут работать идеально чисто и быстро, как в ваниле!

## 🌐 Что такое IPv4 и IPv6 в меню ESC? (Простыми словами)

В нашем моде под кнопкой «Save and Quit to Title» появился переключатель **Internet: IPv4 / IPv6**. Он не показывает ваш реальный адрес в целях безопасности, а перестраивает внутреннюю работу Java и Windows, чтобы роутер например Дом.ру гарантированно открыл порты. Вот для чего это нужно:

### 🔹 Режим: IPv4 (Стандартное подключение)
* **Как работает:** Мод использует классические сетевые каналы компьютера.
* **В чём сложность:** Из-за того, что старые адреса IPv4 в интернете заканчиваются, провайдеры часто выдают игрокам **«серые» IP-адреса**. С таким адресом ваш ПК спрятан за общей защитой оператора, и роутер может сбрасывать пакеты друзей при попытке подключиться.
* **Когда выбирать:** Используйте этот режим по умолчанию для обычной игры с друзьями.

### 🔹 Режим: IPv6 (Мощное пробитие сети)
* **Как работает:** Мод переключает сетевую карту Java на современные интернет-протоколы IPv6. 
* **Почему это круто:** В режиме IPv6 провайдерские блокировки и ограничения «серых» IP полностью обходят стороной. Сетевые ворота роутера пробиваются напрямую без костылей!
* **Главный плюс:** Вам **НЕ нужно** показывать или давать другу никакой другой, длинный или непонятный адрес. Ваш IP всегда надёжно защищён заглушкой `[HIDDEN]` от чужих глаз. Мод сам под капотом настроит скрытую передачу данных, чтобы роутер Дом.ру пропустит друга в ваш мир с первой секунды!
* **Когда выбирать:** Если друг никак не может к вам подключиться, если у него мобильный интернет (4G/5G) или если кнопка IPv4 выдаёт ошибку.

## 🎮 Информация для игроков (Как пользоваться новыми функциями):

### 1. Как зарегистрироваться на сервере (Для заходящих игроков):
* При первом заходе на сервер ваш персонаж будет **намертво заморожен** на спавне — вы не сможете ходить, прыгать и ломать блоки, пока не создадите пароль.
* Откройте чат (клавиша **T**) и введите команду: `/register <ваш_пароль> <повтор_пароля>`. 
  * *Пример:* `/register вашпароль`
* При каждом следующем заходе на этот сервер вам нужно будет просто ввести свой пароль: `/login <ваш_пароль>`.
  * *Пример:* `/login вашпароль`
* **Внимание:** Вводите пароль внимательно! После 3-х неверных попыток ввода сервер автоматически выкинет вас (кикнет) в главное меню. Ваш пароль полностью скрыт от других игроков и никто его не увидит.

### 2. Как настроить лимит игроков (Для создателя сервера):
* Если к вам хочет зайти большая компания, откройте меню паузы (**ESC**).
* Посмотрите в **верхний правый угол** экрана — там появилось небольшое окошко с цифрой `8`.
* Кликните по нему, сотрите старое число и введите любое новое количество слотов (например, `54` или `100`).
* Нажмите кнопку **Set Max Players** прямо рядом с окошком. Лимит мгновенно применится, и друзья в списке серверов сразу увидят новые свободные места!

Версия 5.0.0 построена на базе сквозной синхронизации всех сетевых модулей. Мод работает как единый перекресток систем:

       [MCMultiplayer Core]
                │
 [Global Server]┼[Lan Server]
 (Интернет/UPnP)│ (Локальная сессия)
                │
          [Multiplayer]

* **Global Server (Приоритет №1)** — отвечает за внешние шлюзы [Standard Configuration]. Мод автоматически оптимизирует сетевой стек Java (Dual-Stack IPv4/IPv6), отправляет SSDP-команды на роутер для пробития портов и вытаскивает честный IP через глобальную сеть [Standard Configuration].
* **Lan Server** — отвечает за внутреннюю инициализацию [Standard Configuration]. Вызывается автоматически в памяти игры без ручного запуска.
* **Multiplayer** — итоговый результат, объединяющий локальный сервер и глобальный интернет в одну удобную сессию для твоих друзей [Standard Configuration]!

## 🛠️ Новые функции версии 5.0.0 (Change Log):

* **Умная кнопка `Optimize All`** — добавлена в нижний левый угол экрана ESC, идеально выровнена по высоте с переключателем интернета и полностью переведена на английский язык для чистоты интерфейса [Standard Configuration].
* **Полная автоматизация «В один клик»** — нажатие на `Optimize All` запускает скрытый изолированный поток `new Thread()`, который настраивает приоритеты Java, открывает сервер, пробивает роутер и копирует IP [Standard Configuration]!
* **Авто-публикация мира (LAN Force-Publish)** — если вы забыли запустить сервер кнопкой по центру, оптимизатор сам автоматически опубликует ваш мир в сеть на случайный безопасный порт [Standard Configuration].
* **Авто-пробитие роутера (UPnP Punch)** — мод сам отправляет широковещательный SSDP-пакет на шлюз вашего провайдера, принудительно заставляя домашний роутер открыть порты наружу [Standard Configuration].
* **Чистый сбор IP без сайтов** — интеграция с быстрым системным сервисом `icanhazip.com`. Мод считывает внешний IP, склеивает его с динамическим портом игры и мгновенно копирует готовый адрес в буфер обмена Windows [Standard Configuration].
* **Полная синхронность IPv4/IPv6** — система сама определяет тип вашего интернета, и при использовании IPv6 автоматически оборачивает адрес в квадратные скобки `[...]` для корректного подключения друзей [Standard Configuration].
